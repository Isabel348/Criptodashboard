API de CoinMarketCap Keyless

Esta página muestra cómo usar la API de CoinMarketCap para obtener datos de criptomonedas en tiempo real. Puedes probar los endpoints sin necesidad de registrarte usando el modo Keyless.

Autenticación

La API usa el header X-CMC_PRO_API_KEY para autenticación. El modo Keyless usa /trial-pro-api en la URL sin header.

1

Obtén tu API Key

Regístrate gratis en pro.coinmarketcap.com para obtener una API key del plan Basic.

2

Agrega el header de autenticación

Incluye X-CMC_PRO_API_KEY: tu-api-key en los headers de cada petición.

3

Haz tu primera petición

Usa la URL base https://pro-api.coinmarketcap.com/v1/ para endpoints autenticados o https://pro-api.coinmarketcap.com/trial-pro-api/ para modo Keyless.

Ejemplo: cURL

Obtén el listado de las 10 principales criptomonedas:

# Sin clave, sin headers, sin registro
curl -G "https://pro-api.coinmarketcap.com/trial-pro-api/v1/cryptocurrency/listings/latest" \
  --data-urlencode "start=1" \
  --data-urlencode "limit=10" \
  --data-urlencode "convert=USD"

Ejemplo: JavaScript (Fetch)

Usando la API Keyless desde el navegador:

async function getTopCryptos() {
  const url = 'https://pro-api.coinmarketcap.com/trial-pro-api/v1/cryptocurrency/listings/latest?start=1&limit=10&convert=USD';
  const res = await fetch(url);
  const json = await res.json();
  return json.data;
}

// Con API key autenticada:
const API_KEY = 'tu-api-key-aqui';
const resAuth = await fetch('https://pro-api.coinmarketcap.com/v1/cryptocurrency/listings/latest?start=1&limit=10&convert=USD', {
  headers: { 'X-CMC_PRO_API_KEY': API_KEY }
});

Parámetros Comunes

ParámetroTipoDescripción
startintPosición inicial del ranking (por defecto 1)
limitintNúmero de resultados (1-5000, por defecto 100)
convertstringMoneda de conversión (USD, EUR, BTC, ETH...)
sortstringOrdenar por: market_cap, volume_24h, price, name...
sort_dirstringDirección: asc o desc
cryptocurrency_typestringFiltrar por: all, coins, tokens
tagstringFiltrar por categoría: defi, meme, real-world-assets...
